2 .  Data structures

2.1  PDA seeds

["escrow", maker, resolver, hash_secret, role_byte]
	•	role_byte = 0x00 for Dst escrow clones on Solana.
	•	Seeds must be identical to those used by the Go coordinator so both sides can deterministic‑ally derive addresses off‑chain.

2.2  Zero‑copy account (Escrow)

#[zero_copy]                                  // pinocchio directive
pub struct Escrow {
    pub maker: Pubkey,                        // matches EVM’s maker
    pub resolver: Pubkey,                     // matches EVM’s resolver
    pub hash_secret: [u8; 32],                // keccak256(S)
    pub token_mint: Pubkey,                   // SPL token
    pub amount: u64,                          // token amount in smallest unit
    pub safety_deposit_lamports: u64,         // paid at init, rewarded at exit
    pub merkle_root: [u8; 32],                // 0 = single‑fill
    pub filled_index: u32,                    // next expected Merkle leaf index
    pub timelocks: [u64; 7],                  // seconds offsets from deployed_at
    pub deployed_at: u64,                     // unix‑epoch seconds
    pub bump: u8,
}

The seven timelock indices mirror TimelocksLib.Stage on EVM:

Index	Stage	Meaning
 0	src_exclusive_withdraw	(Already passed) – source resolver window
 1	src_public_withdraw	(Already passed)
 2	dst_exclusive_withdraw	Only resolver may withdraw
 3	dst_public_withdraw	Anyone may withdraw
 4	dst_exclusive_cancel	Only resolver may cancel
 5	dst_public_cancel	Anyone may cancel
 6	rescue	Anyone may rescue dust

3 .  Instruction set (exact wire format)

Use pinocchio code‑gen to derive an enum identical to:

#[derive(ZeroCopy, FromBytes, ToBytes)]
pub enum EscrowIx {
    /// Create the destination escrow PDA
    CreateDstEscrow(EscrowInit),                 // Accounts: [payer, resolver, escrow_pda, system, token, clock]
    /// Withdraw to caller (or target) with secret + optional Merkle proof
    Withdraw      { secret: [u8;32], proof: Vec<[u8;32]> },
    WithdrawTo    { secret: [u8;32], target: Pubkey, proof: Vec<[u8;32]> },
    /// Cancel after timelock
    Cancel,
    PublicCancel,
    /// Execute withdraw via public path
    PublicWithdraw{ secret: [u8;32], proof: Vec<[u8;32]> },
    /// Drain dust after long timeout
    RescueFunds,
}

EscrowInit struct fields (all little‑endian):

Field	Type	Notes
maker	Pubkey	EVM maker address on Solana (just opaque bytes)
resolver	Pubkey	The resolver signer
hash_secret	[u8;32]	Keccak‑256 digest
token_mint	Pubkey	SPL token
amount	u64	Token amount
safety_deposit_lamports	u64	Native SOL deposit
merkle_root	[u8;32]	0 for single‑fill swaps
timelocks	[u64;7]	Seconds offsets
bump	u8	PDA bump

4 .  Execution rules (handler pseudocode)

4.1  create_dst_escrow

1. Verify signer == resolver pubkey.
2. Derive PDA with seeds; compare to provided account.
3. Ensure PDA is uninitialised.
4. Allocate Escrow via SystemProgram::create_account:
   - lamports = rent_exempt + safety_deposit_lamports (checked vs. param)
   - space     = size_of::<Escrow>()
5. Serialize Escrow struct.

4.2  withdraw / withdraw_to

Pre‑conditions:
  a) clock.now  ≥ deployed_at + timelocks[2]          (exclusive phase)
     OR clock.now ≥ deployed_at + timelocks[3]        (public phase)
  b) keccak256(secret) == hash_secret
  c) If merkle_root != 0:
        verify(proof, merkle_root, secret, filled_index)   // depth ≤ 32
        filled_index += 1
Actions:
  1. Transfer `amount` SPL tokens from escrow_pda's ATA → target ATA
  2. Transfer `safety_deposit_lamports` SOL → msg.sender
  3. Close PDA (set lamports = 0) if single‑fill or last leaf.

4.3  cancel / public_cancel

Pre‑conditions mirror withdraw but using timelocks[4] / timelocks[5].
Transfers SPL tokens back to resolver; pays deposit to caller.

4.4  rescue_funds

Require clock.now ≥ deployed_at + timelocks[6].
Transfer entire remaining balance (SPL + lamports) → resolver.
Close PDA.

4.5  Compute‑unit optimisation
	•	Use keccak::hashv(&[&secret]) (260 CU).
	•	Hard‑cap loop over Merkle proof to 32 iterations.
	•	Precompute account_info.key hashes outside loop.

Benchmarks must stay < 200 k CU for withdraw with a 32‑level proof.

5 .  Security & invariant checklist

Category	Mandatory guard
Rent	Escrow PDA must remain rent‑exempt at all times.
Overflow	Use checked_add / checked_mul on SPL transfers.
Duplicate secret	filled_index strict monotone increment OR merkle_root == 0.
Replay‑protection	PDA closed (lamports = 0) after last successful action.
Re‑entrancy	No CPI back into itself; transfer lamports last.
Upgradability	Program is immutable (no upgrade authority).

6 .  Testing strategy

6.1  Frameworks (based on Torii Security guide)

Layer	Tool	Why
Unit	solana_program_test (Rust)	Fast, single‑process BPF execution × mocked clock/slot.
Integration	solana_program_test + real token mints	Multiple instructions in one test; asserts lamport balances.
E2E	solana-test-validator spun up by Rust test harness	Validates PDA addresses from JSON hand‑shake with Go coordinator.
Fuzz / property	cargo‑fuzz with libfuzzer harness around verify_merkle & timelock maths	Catches overflow & panic edge‑cases.

6.2  Concrete test files

File	Scenario	Expectation
happy_path.rs	Resolver fills, reveals, withdraws	SPL → maker, deposit → resolver
public_withdraw.rs	Resolver disappears; stranger executes after TL3	Deposit → stranger
cancel.rs	Resolver cancels after TL4	SPL → resolver
merkle_depth32.rs	32‑level proof; verify filled_index increments	CU < 200 k, index == 32
cu_budget.rs	Measures CU on every ix; fails if any > 200 k	—

All tests must pass with cargo test -- --nocapture.

  build:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        toolchain: [stable, "1.77.0"]
    steps:
      - uses: actions/checkout@v4
      - uses: actions-rs/toolchain@v1
        with: { toolchain: ${{ matrix.toolchain }}, default: true }
      - run: rustup component add clippy rustfmt
      - run: cargo fmt -- --check
